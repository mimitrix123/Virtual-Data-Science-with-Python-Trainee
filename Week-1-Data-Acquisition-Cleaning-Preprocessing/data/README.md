# Dataset Setup

Download the Titanic `train.csv` file from the Kaggle Titanic competition and place it in the project directory before running `week1_data_cleaning.py`.

## Expected file

`train.csv`

The standard training dataset contains 891 rows and 12 columns.

## Provenance

Kaggle — Titanic: Machine Learning from Disaster

https://www.kaggle.com/c/titanic/data?select=train.csv

## Privacy and reproducibility

Keep the downloaded raw dataset unchanged. Do not commit Kaggle credentials, API tokens, or other secrets to this repository.
